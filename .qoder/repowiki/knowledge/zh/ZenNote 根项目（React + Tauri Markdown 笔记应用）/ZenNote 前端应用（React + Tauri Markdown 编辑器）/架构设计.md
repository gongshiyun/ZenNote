入口链为 `main.tsx` → `App.tsx` → `<AppShell />`：`main.tsx` 检测 Tauri 导出窗口标签（`pdf-export-*`）并跳过挂载，避免 PDF 导出时触发持久化副作用；`App.tsx` 集中解析 light/dark/system 主题模式并写入 `document.documentElement.classList` 与 `data-theme`/`data-font` 属性；`AppShell` 作为壳层容器组合 Titlebar、TabBar、FileTree、Editor、Outline、SearchPanel、SettingsDialog、ShortcutsPanel、StatusBar，并通过 lazy/Suspense 按需加载重型面板。

- 状态中心 `store/index.ts` 使用 Zustand 单一 store 组合 EditorSlice、FileTreeSlice、OutlineSlice、ThemeSlice、ConfigSlice、LocaleSlice、UpdateSlice、UISlice 八个切片，组件通过 `useStore(s => s.xxx)` 订阅，跨组件通信完全依赖 store。
- 领域层 `domain/` 提供 FileNode/Heading/AppConfig 等类型及 parseHeadings、parentDir、isWithinWorkspace 等纯函数，被 store 与各组件共享，通过 `domain/index.ts` barrel 暴露。
- 服务层 `services/fileService.ts` 封装所有 Tauri IPC 与文件系统副作用，通过 barrel `services/index.ts` 暴露 readFile/writeFile/openWorkspace/saveImage 等接口，组件不直接调用 Tauri API。
- 国际化采用自实现轻量 t() 方案，locale 值同时写入 localStorage 并与 store 的 LocaleSlice 解耦；语言切换时通过订阅 locale 触发整棵组件树重渲染以刷新文案。
- `plugins/` 目录预留扩展点当前未启用。
- 侧边栏与大纲面板在 `AppShell` 内通过直接 DOM 操作（style.width）实现拖拽调整宽度，避免高频 mousemove 触发 React 重渲染。
