模块由四个文件构成清晰的三层结构：
- 挂载层（main.tsx）：使用 ReactDOM.createRoot 将 <App /> 渲染到 #root 节点，并包裹在 React.StrictMode 中。
- 应用壳层（App.tsx）：通过 zustand store（useStore）读取 mode/resolvedMode，利用 useEffect + window.matchMedia 监听系统主题变化，动态切换 document.documentElement 的 'dark' 类名，最终只渲染 <AppShell />。
- 样式层（index.css + App.css）：index.css 定义 :root CSS 自定义属性（--text/--bg/--accent 等）及 @media (prefers-color-scheme: dark) 暗色覆盖；App.css 定义页面级布局样式（.hero/#center/#next-steps 等），两者均通过 CSS 变量实现主题化。
依赖方向单向向下：main.tsx → App.tsx → components/layout/AppShell，不反向依赖任何业务组件。
