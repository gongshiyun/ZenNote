- 入口链：`main.tsx` 挂载 React 根节点并引入全局样式，`App.tsx` 负责主题模式解析（light/dark/system）并通过 `useStore` 订阅 theme slice，最终渲染 `<AppShell />`。
- 状态中心：`store/index.ts` 使用 Zustand 的单一 store 组合 EditorSlice、FileTreeSlice、OutlineSlice、ThemeSlice、ConfigSlice、LocaleSlice、UIState 七个切片，所有组件通过 `useStore(s => s.xxx)` 订阅，跨组件通信完全依赖 store。
- 组件分层：`components/layout/` 提供 AppShell、StatusBar、Titlebar 等壳层；业务面板（editor、filetree、outline、search、dialogs）均为无状态或弱状态 UI，通过 store 与父级交互。
- 国际化：`i18n/index.ts` 维护当前 locale 并提供 `t()` 获取翻译对象，locale 值同时写入 localStorage 并与 store 的 LocaleSlice 解耦。
- 插件与扩展点：`plugins/` 与 `lib/` 目录为空，预留插件加载与工具函数扩展位置，当前未启用。
- 类型共享：`domain/types.ts` 定义跨模块共享的类型，被 store 与各组件共同引用。
