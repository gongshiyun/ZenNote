根目录作为整个 ZenNote 应用的统一入口，前端（frontend_app）由 Vite 构建、React 渲染并通过 @tauri-apps/api 调用 Tauri 后端（tauri_backend）暴露的文件系统命令；文档（docs）集中存放产品与技术规范。构建流程由 package.json 的 scripts 统一编排：dev 启动 Vite 开发服务器，build 先执行 tsc -b 进行 TypeScript 项目引用检查再 vite build，lint 使用 oxlint 进行代码检查。tsconfig.json 通过 references 聚合 tsconfig.app.json 与 tsconfig.node.json，确保前后端共享的类型定义一致性。Tauri CLI（@tauri-apps/cli）负责将前端产物打包为桌面可执行程序，使前端与 Rust 后端在同一个进程中运行并通过 IPC 通信。
