本模块为纯文档型 leaf 模块，包含五份相互关联的 Markdown 文档：PRD.md 定义产品定位、功能需求与非功能指标；TECH-DESIGN.md 描述 Tauri v2 + React + Milkdown + CodeMirror 6 的技术架构、Zustand 状态管理、Rust 后端命令接口与依赖清单；UI-DESIGN.md 规定三栏布局、色彩系统、字体体系与各组件规格；UX-REVIEW.md 以 Apple HIG 视角进行全链路体验审计，按 P0-P3 分级列出缺失项与修复方案；MARKDOWN-RENDERING.md 逐条定义 20+ 种 Markdown 语法的渲染态/编辑态切换、光标交互与边界情况。文档间通过交叉引用形成闭环：PRD 引用 MARKDOWN-RENDERING.md 作为编辑器实现依据，TECH-DESIGN.md 汇总所有技术选型并给出 Rust/Tauri 命令签名，UX-REVIEW.md 明确需要更新 PRD 与 UI-DESIGN 的具体条目。
