根目录作为 ZenNote 应用的统一编排层：package.json 的 scripts 串联 dev/build/lint/preview 流程；tsconfig.json 通过 references 聚合 tsconfig.app.json（前端）与 tsconfig.node.json（Node/Tauri 侧），保证 TypeScript 类型一致性；Vite 构建产物由 Tauri CLI 打包进 Rust 后端进程，前端通过 @tauri-apps/api 调用 tauri_backend 暴露的文件系统命令完成 IPC 通信；docs 子模块独立维护产品设计与技术规范，不参与运行时依赖。
