入口链为 `main.tsx` → `App.tsx` → `<AppShell />`：`App.tsx` 解析 light/dark/system 主题模式并写入 DOM class，`AppShell` 作为壳层容器组合 StatusBar、Titlebar 与各业务面板（editor、filetree、outline、search、dialogs）。状态中心 `store/index.ts` 使用 Zustand 单一 store 组合 EditorSlice、FileTreeSlice、OutlineSlice、ThemeSlice、ConfigSlice、LocaleSlice、UIState 七个切片，所有组件通过 `useStore(s => s.xxx)` 订阅，跨组件通信完全依赖 store。国际化采用自实现轻量 t() 方案，locale 值同时写入 localStorage 并与 store 的 LocaleSlice 解耦。类型定义集中在 `domain/types.ts` 被 store 与各组件共享，`plugins/` 与 `lib/` 目录预留扩展点当前未启用。
