模块遵循 Tauri 2 标准分层结构：`src/main.rs` 仅作为平台入口（Windows release 下通过 `windows_subsystem = "windows"` 隐藏控制台），委托给 `app_lib::run()`；核心逻辑集中在 `src/lib.rs`，以 `#[tauri::command]` 宏声明 11 个文件系统与导出命令并通过 `tauri::generate_handler!` 注册到 invoke handler。数据模型 `FileNode` 递归表示 Markdown 工作区树，由 `build_tree` 函数基于 `walkdir` 递归构建（仅包含 `.md` 文件并跳过隐藏文件）。插件体系通过 `tauri::Builder` 链式装配 dialog、fs、shell、process、updater 五个插件，其中 log 插件仅在 debug 模式下启用。PDF 导出在 Windows 上通过 `webview2-com` + `windows` crate 直接调用 WebView2 的 `PrintToPdf` API，非 Windows 平台返回错误。权限模型由 `capabilities/default.json` 声明式控制，`tauri.conf.json` 定义单窗口配置及前后端构建流程（dev 指向 Vite 5173，build 输出到 ../dist）。构建流程由 `build.rs` 调用 `tauri_build::build()` 生成上下文，`Cargo.toml` 将 crate 编译为 staticlib/cdylib/rlib 三种类型以适配 Tauri 打包器。
