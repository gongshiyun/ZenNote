根目录作为 ZenNote 的顶层编排层：package.json 定义 dev/build/lint/preview/test 等脚本，其中 build 先执行 tsc -b 进行跨子项目的类型检查，再交由 vite build 生成静态资源；tsconfig.json 通过 project references 聚合 tsconfig.app.json（frontend_app）与 tsconfig.node.json（tauri_backend），确保前后端 TypeScript 类型一致性；vite.config.ts 配置 React + TailwindCSS 插件并固定开发端口 5173；构建产物由 @tauri-apps/cli 打包进 Tauri 2 Rust 后端进程，前端通过 @tauri-apps/api 调用 tauri_backend 暴露的文件系统命令完成 IPC 通信；docs 子模块独立维护产品设计与技术规范，不参与运行时依赖。
