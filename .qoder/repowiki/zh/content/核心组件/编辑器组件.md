## 简介
本文件为 ZenNote 的 Markdown 编辑器组件提供系统化、可操作的文档。重点覆盖：
- Editor.tsx 的实现细节：Markdown 渲染、语法高亮、实时预览、HTML块渲染
- FindReplaceBar 查找替换栏的功能与集成方式
- TableContextMenu 表格上下文菜单的交互逻辑与自定义操作
- 编辑器配置项、快捷键绑定、事件处理机制
- 扩展编辑器的具体示例（以路径引用代替代码片段）
- 与状态管理的集成方式及性能优化策略
- **v0.8.1重大更新**：编辑器滚动修复、代码块样式重新设计、TOC输入增强、图片交互改进和性能优化

## 项目结构
编辑器相关代码位于 src/components/editor 下，包含三个关键子组件：
- Editor.tsx：主编辑器容器，负责 Markdown 渲染、预览模式切换、事件与快捷键、与 store 的状态同步、HTML块渲染、源码模式大纲导航、Typora风格HTML块编辑、图片对齐功能、KaTeX数学公式渲染、YAML frontmatter支持、自动目录生成、脚注交叉引用导航
- FindReplaceBar.tsx：查找替换工具栏，支持搜索、高亮匹配、替换、大小写敏感等
- TableContextMenu.tsx：表格右键菜单，支持插入行列、删除、合并单元格等常用操作

## 架构总览

- 用户输入通过 Editor 捕获并转换为 store 中的 Markdown 文本
- FindReplaceBar 与 TableContextMenu 作为无状态或轻状态 UI，调用 store 提供的动作方法
- useMermaid 钩子在预览模式下按需渲染 Mermaid 图表，并提供丰富的交互功能
- 全局样式由 globals.css 统一注入
- **v0.8.1新增** editorScrollEl()函数解决Crepe框架的滚动容器识别问题
- **v0.8.1新增** znCodeHighlightStyle主题感知语法高亮系统

## 详细组件分析

### Editor.tsx 组件分析
- Markdown 渲染与预览
  - 编辑模式：基于底层编辑器实例进行文本输入与语法高亮
  - 预览模式：将 Markdown 转为 HTML，并在需要时渲染 Mermaid 图表
  - 实时同步：对 content 变更进行防抖/节流，避免频繁重渲染
- 快捷键绑定
  - 全局快捷键：保存、切换预览、查找替换、插入表格等
  - 局部快捷键：在表格上下文中启用行列操作
- 事件处理
  - onChange/onSelect/onCursorChange：驱动 store 更新与 UI 反馈
  - onMount/onUnmount：初始化与销毁资源（如 Mermaid 渲染、事件监听）
- 配置选项
  - 主题、语言、自动保存间隔、是否启用 Mermaid、是否显示行号等
- 错误处理
  - 捕获 Markdown 解析异常，降级到纯文本预览
  - 记录日志并提示用户
- **v0.8.1新增** editorScrollEl()滚动修复功能
  - 解决Crepe框架中.ProseMirror父元素不是实际滚动容器的问题
  - 递归查找具有auto/scroll overflow属性的真实滚动元素
  - 修复滚动位置保存/恢复功能和随机自动滚动问题
  - 在编辑器初始化、滚动位置恢复、周期性保存等场景中使用
- **v0.8.1新增** znCodeHighlightStyle主题感知语法高亮
  - 定义完整的CodeMirror语法高亮样式映射
  - 支持GitHub Light（浅色模式）和One Dark（深色模式）配色方案
  - 使用CSS变量实现主题切换，无需重新计算样式
  - 覆盖关键字、字符串、注释、数字、函数、类型、变量等所有语法元素
- **v0.8.1新增** TOC输入规则增强
  - 支持全角括号【】和［］的识别和转换
  - 正则表达式/^[\[【［]\s*toc\s*[\]】］]$/i匹配多种括号格式
  - 统一的输入规则和自动转换插件确保兼容性
  - 支持中文输入法下的意外输入场景
- **v0.8.1新增** 图片点击交互优化
  - 改进图片点击事件处理逻辑
  - 优化对齐工具栏的定位和显示
  - 隐藏Crepe默认的caption按钮和输入框
  - 提供更直观的Typora风格图片交互体验
- **v0.8.1新增** 性能优化改进
  - 优化滚动事件处理，减少不必要的重渲染
  - 改进内存管理和资源清理
  - 优化事件监听器的注册和注销
  - 提升大文档的处理性能

**已更新** v0.8.1版本的重大更新显著提升了编辑器的稳定性和用户体验，特别是滚动修复、代码块样式、TOC输入和图片交互方面的改进。

## 性能考虑
- 渲染优化
  - 预览模式下的 Markdown 转 HTML 使用缓存与懒加载
  - Mermaid 渲染仅在可见区域或切换预览时触发，使用 Milkdown 原生 renderPreview 提升性能
  - **v0.8.1新增** editorScrollEl()函数优化滚动容器检测，避免不必要的DOM查询
  - **v0.8.1新增** znCodeHighlightStyle使用CSS变量实现主题切换，无需重新计算样式
- 输入优化
  - 对 onChange 进行防抖/节流，减少 store 更新频率
  - 大文档分块渲染，避免主线程阻塞
  - **v0.8.1新增** 优化的滚动事件处理，减少selectionchange事件的触发频率
- 内存管理
  - 组件卸载时清理事件监听与定时器
  - 释放 Mermaid 实例与 DOM 引用
  - **v0.8.1新增** 改进的事件监听器清理机制
- 样式与主题
  - 通过 CSS 变量控制主题，避免重复计算
  - **v0.8.1新增** 主题感知的代码块高亮，支持明暗主题无缝切换
- **v0.8.1新增** 性能监控和优化
  - 跟踪滚动事件处理性能
  - 优化TOC输入规则的匹配效率
  - 改进图片点击事件的性能

**已更新** v0.8.1版本的性能优化主要体现在滚动修复、主题感知高亮、事件处理和内存管理方面，显著提升了编辑器的响应速度和稳定性。

## 故障排查指南
- 常见问题
  - 预览空白：检查 Markdown 解析错误与 Mermaid 初始化
  - 查找无结果：确认正则/大小写设置与内容编码
  - 表格操作无效：确认选区是否为表格节点
  - Mermaid 渲染异常：检查 Milkdown renderPreview 函数调用是否正确
  - **v0.8.1新增** 滚动位置丢失：检查editorScrollEl()函数是否正确识别滚动容器

## 结论
ZenNote 的编辑器组件以清晰的职责划分与单向数据流为核心，结合防抖/节流、按需渲染与良好的错误处理，提供了稳定高效的 Markdown 编辑体验。**v0.8.1版本的重大更新**通过editorScrollEl()滚动修复、znCodeHighlightStyle主题感知高亮、TOC输入增强和图片交互优化，显著提升了编辑器的稳定性和用户体验。这些改进解决了Crepe框架的滚动容器识别问题，实现了真正的主题感知代码高亮，增强了多语言输入的兼容性，并优化了图片操作的交互体验。通过这些改进，用户可以享受更流畅的编辑体验、更准确的滚动位置保存、更美观的代码高亮效果、更智能的TOC输入处理和更直观的图片操作界面。
