## 概述
ZenNote的样式系统基于现代CSS架构，采用模块化设计原则，支持明暗主题切换、响应式布局和组件样式隔离。系统通过CSS变量实现主题定制，确保样式的一致性和可维护性。最新的更新包括状态栏增强（阅读时间估算和保存时间戳）、图片查看器改进（点击缩放和滚轮缩放）、代码块复制按钮以及中文标点符号自动配对功能，显著提升了用户体验和编辑效率。

// 主题管理器
const ThemeManager = {
  setTheme(theme: 'light' | 'dark') {
    document.documentElement.setAttribute('data-theme', theme);

  getTheme(): string {
    return localStorage.getItem('theme') || 'light';
  }

## HTML块编辑界面
**最新更新** 实现了完整的HTML块编辑界面，支持所见即所得预览和源代码编辑模式的无缝切换。

### 编辑模式切换
HTML块节点视图支持两种编辑模式：
- **预览模式**: 显示渲染后的HTML内容
- **源码模式**: 显示原始HTML源代码，支持直接编辑

### 节点视图实现
```typescript
function createHtmlNodeView(node: any, view: any, getPos: any) {
  let editing = false;
  const dom = document.createElement("span");
  dom.setAttribute("data-type", "html");

  const renderPreview = () => {
    editing = false;
    dom.className = "zn-html-node zn-html-render" + (isBlockHtml(currentNode.attrs.value) ? " zn-html-block" : "");
    dom.innerHTML = renderHtmlValue(currentNode.attrs.value);
  };

  const enterEdit = () => {
    editing = true;
    dom.className = "zn-html-node zn-html-source" + (isBlockHtml(currentNode.attrs.value) ? " zn-html-block" : "");
    dom.innerHTML = "";
    const ta = document.createElement("textarea");
    ta.className = "zn-html-textarea";
    ta.value = currentNode.attrs.value;
    // 处理编辑完成事件
    ta.addEventListener("blur", () => {
      if (!editing) return;
      editing = false;
      const newValue = ta.value;
      // 保存编辑内容并重新渲染
      view.dispatch(view.state.tr.setNodeMarkup(pos, undefined, { value: newValue }));
    });
    dom.appendChild(ta);
    ta.focus();
  };
}
```

### HTML内容安全处理
系统内置了HTML内容安全过滤器，防止恶意代码执行：
- 移除script、iframe、object、embed等危险标签
- 过滤javascript:协议的链接
- 清理所有on*事件处理器

## 焦点模式增强
**最新更新** 增强了焦点模式功能，当启用时会自动淡化除光标所在块之外的所有顶级块，提供更好的专注编辑体验。

### 焦点模式实现原理

```css

```

### 焦点检测逻辑
```typescript
// 计算焦点装饰
const computeFocusDecos = (state: any) => {
  const focusModeOn = useStore.getState().focusMode;
  const decos: any[] = [];
  const sel = state.selection;
  
  if (focusModeOn && $head.depth >= 1) {
    const topFrom = $head.before(1);
    state.doc.forEach((node: any, offset: number) => {
      if (offset !== topFrom) {
        decos.push(Decoration.node(offset, offset + node.nodeSize, { class: "zn-dimmed" }));
      }
    });
  }
  
  return decos.length ? DecorationSet.create(state.doc, decos) : DecorationSet.empty;
};
```

## Crepe编辑器间距控制优化

### 自定义间距配置
```css

/* 响应式间距调整 */

  .crepe-editor {
    margin: var(--editor-margin-mobile, 0.5rem);
    padding: var(--editor-padding-mobile, 1rem);
  }
}
```

### 用户定制优势
- **完全可控**: 用户可以通过CSS变量精确控制编辑器的所有间距
- **主题兼容**: 间距设置自动跟随主题变化
- **响应式支持**: 支持不同屏幕尺寸的间距适配
- **一致性保证**: 统一的间距控制机制确保界面一致性

## 新增：状态栏增强功能

### 阅读时间估算
状态栏现在集成了智能阅读时间估算功能，基于文档字数和内容复杂度计算预计阅读时间。

#### 估算算法
系统使用400字/分钟的平均阅读速度来计算阅读时间：
- 中文汉字单独计数
- 英文单词按空格分割计数
- 空文档返回0分钟
- 非空文档至少显示1分钟

#### 实现原理
```typescript
// 阅读时间估算函数
export function estimateReadingTime(content: string): number {
  const { totalWords } = computeWordCount(content);
  if (totalWords <= 0) return 0;
  return Math.max(1, Math.ceil(totalWords / WORDS_PER_MINUTE));
}
```

### 最后保存时间戳
状态栏显示文档的最后保存时间，帮助用户了解文档的更新状态。

#### 时间格式化
- 格式：HH:MM（24小时制）
- 仅显示当前会话的保存时间
- 未保存时显示"未保存"状态
- 已保存时显示"已保存 HH:MM"

#### 状态指示
- **未保存状态**: 橙色圆点 ● + "未保存"
- **已保存状态**: 绿色对勾 ✓ + "已保存" + 时间戳

### 状态栏布局优化
状态栏采用Flexbox布局，支持响应式显示：
- 左侧：源模式切换按钮

## 新增：中文标点符号自动配对

### 全角标点支持
系统支持常见全角中文标点的自动配对输入，提升中文输入体验。

#### 支持的标点符号
- **括号类**: `（` → `）`
- **方括号类**: `【` → `】`
- **书名号类**: `「` → `」`, `『` → `』`

### 智能配对逻辑
```typescript
// 中文标点配对映射
const CN_PAIRS: Record<string, string> = { 
  "（": "）", 
  "【": "】", 
  "「": "」", 
  "『": "」" 
};

// beforeinput事件处理
const onBeforeInput = (e: Event) => {
  const ie = e as InputEvent;
  if (ie.inputType !== "insertText" || !ie.data) return;
  const closing = CN_PAIRS[ie.data];
  if (!closing) return;
  
  // 检查光标位置是否为空
  const sel = pmView.state.selection;
  if (!sel.empty) return;
  
  // 避免重复配对
  try {
    const next = pmView.state.doc.textBetween(sel.from, Math.min(sel.from + 1, pmView.state.doc.content.size), "");
    if (next === closing) return; // 如果后面已经有闭合符号，则不配对
    
    // 插入配对符号并将光标定位在中间
    ie.preventDefault();
    const tr = pmView.state.tr.insertText(ie.data + closing, sel.from);
    tr.setSelection(TextSelection.create(tr.doc, sel.from + 1));
    pmView.dispatch(tr);
  } catch { /* 出错时不影响正常输入 */ }
};
```

### 输入时机控制
- **IME输入法**: 支持输入法提交时的自动配对
- **光标位置**: 仅在光标位置为空时触发配对
- **防重复**: 避免在已有闭合符号的情况下重复配对
- **错误处理**: 配对失败时不影响正常输入流程

### 用户体验优化
- **即时反馈**: 输入开括号后立即显示闭括号
- **光标定位**: 光标自动定位在两个配对符号之间
- **无缝集成**: 与现有输入法功能完美兼容
- **容错处理**: 异常情况不影响正常编辑体验
