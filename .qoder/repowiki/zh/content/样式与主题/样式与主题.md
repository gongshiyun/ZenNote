## 概述
ZenNote的样式系统基于现代CSS架构，采用模块化设计原则，支持明暗主题切换、响应式布局和组件样式隔离。系统通过CSS变量实现主题定制，确保样式的一致性和可维护性。新增的字体堆栈系统确保了12种不同字体在跨平台环境下的统一渲染效果。最新的更新移除了Crepe编辑器库集成中的硬编码padding值，使用户能够通过自定义margin设置完全控制编辑器间距，提升了系统的可定制性。

## 主题定制机制
主题系统基于CSS变量和数据属性实现，支持运行时切换。

### 主题切换实现
```typescript
// 主题管理器
const ThemeManager = {
  setTheme(theme: 'light' | 'dark') {
    document.documentElement.setAttribute('data-theme', theme);
    localStorage.setItem('theme', theme);
  },
  
  getTheme(): string {
    return localStorage.getItem('theme') || 'light';
  }
};
```

### 标题栏主题集成
```tsx
// Titlebar组件中的主题处理
useEffect(() => {
  const theme = ThemeManager.getTheme();
  document.documentElement.setAttribute('data-theme', theme);
}, []);
```

## Crepe编辑器间距控制优化
**最新更新** 移除了Crepe编辑器库集成中的硬编码padding值，使自定义margin设置成为间距控制的唯一来源，显著提升了用户的定制能力。

### 间距控制改进
之前的版本在Crepe编辑器库中使用了硬编码的padding值，限制了用户对编辑器间距的自定义能力。现在系统完全依赖CSS变量和自定义margin设置来控制编辑器间距。

### 自定义间距配置
```css
/* 通过CSS变量控制编辑器间距 */
.crepe-editor {
  margin: var(--editor-margin, 1rem);
  padding: var(--editor-padding, 1.5rem);
}

/* 响应式间距调整 */
@media (max-width: 768px) {
  .crepe-editor {
    margin: var(--editor-margin-mobile, 0.5rem);
    padding: var(--editor-padding-mobile, 1rem);
  }
}
```

### 用户定制优势
- **完全可控**: 用户可以通过CSS变量精确控制编辑器的所有间距
- **主题兼容**: 间距设置自动跟随主题变化
- **响应式支持**: 支持不同屏幕尺寸的间距适配
- **一致性保证**: 统一的间距控制机制确保界面一致性

```typescript
// SettingsDialog中的配置管理
interface UserSettings {
  theme: 'light' | 'dark';
  fontSize: number;
  lineSpacing: number;
  autoSave: boolean;
  // ... 其他设置项
}

const SettingsManager = {
  saveSettings(settings: UserSettings): void {
    localStorage.setItem('user-settings', JSON.stringify(settings));

};
```

### 步骤2: 在应用中引入主题
```tsx

```

### 步骤3: 动态切换主题
```typescript
const switchTheme = (themeName: string) => {
  document.documentElement.className = themeName;

};
```
