## 概述
ZenNote的样式系统基于现代CSS架构，采用模块化设计原则，支持明暗主题切换、响应式布局和组件样式隔离。系统通过CSS变量实现主题定制，确保样式的一致性和可维护性。最新的更新包括代码块样式的全面重新设计，采用浅灰色背景和无边框设计，以及增强的语法高亮功能，显著提升了代码编辑的视觉体验和可读性。

## HTML块编辑界面
**最新更新** 实现了完整的HTML块编辑界面，支持所见即所得预览和源代码编辑模式的无缝切换。

### 编辑模式切换
HTML块节点视图支持两种编辑模式：
- **预览模式**: 显示渲染后的HTML内容
- **源码模式**: 显示原始HTML源代码，支持直接编辑

### 节点视图实现
```typescript
function createHtmlNodeView(node: any, view: any, getPos: any) {
  let editing = false;
  const dom = document.createElement("span");
  dom.setAttribute("data-type", "html");

  const renderPreview = () => {
    editing = false;
    dom.className = "zn-html-node zn-html-render" + (isBlockHtml(currentNode.attrs.value) ? " zn-html-block" : "");
    dom.innerHTML = renderHtmlValue(currentNode.attrs.value);
  };

  const enterEdit = () => {
    editing = true;
    dom.className = "zn-html-node zn-html-source" + (isBlockHtml(currentNode.attrs.value) ? " zn-html-block" : "");
    dom.innerHTML = "";
    const ta = document.createElement("textarea");
    ta.className = "zn-html-textarea";
    ta.value = currentNode.attrs.value;
    // 处理编辑完成事件
    ta.addEventListener("blur", () => {
      if (!editing) return;
      editing = false;
      const newValue = ta.value;
      // 保存编辑内容并重新渲染
      view.dispatch(view.state.tr.setNodeMarkup(pos, undefined, { value: newValue }));
    });
    dom.appendChild(ta);
    ta.focus();
  };
}
```

### HTML内容安全处理
系统内置了HTML内容安全过滤器，防止恶意代码执行：
- 移除script、iframe、object、embed等危险标签
- 过滤javascript:协议的链接
- 清理所有on*事件处理器

## 焦点模式增强
**最新更新** 增强了焦点模式功能，当启用时会自动淡化除光标所在块之外的所有顶级块，提供更好的专注编辑体验。

### 焦点模式实现原理
焦点模式通过ProseMirror装饰系统实现，使用`zn-dimmed`类名来淡化非活动块：

```css

  transition: opacity 150ms ease;
}
```

### 焦点检测逻辑
```typescript
// 计算焦点装饰
const computeFocusDecos = (state: any) => {
  const focusModeOn = useStore.getState().focusMode;
  const decos: any[] = [];
  const sel = state.selection;
  
  if (focusModeOn && $head.depth >= 1) {
    const topFrom = $head.before(1);
    state.doc.forEach((node: any, offset: number) => {
      if (offset !== topFrom) {
        decos.push(Decoration.node(offset, offset + node.nodeSize, { class: "zn-dimmed" }));
      }
    });
  }
  
  return decos.length ? DecorationSet.create(state.doc, decos) : DecorationSet.empty;
};
```

## Crepe编辑器间距控制优化
**最新更新** 移除了Crepe编辑器库集成中的硬编码padding值，使自定义margin设置成为间距控制的唯一来源，显著提升了用户的定制能力。

### 间距控制改进
之前的版本在Crepe编辑器库中使用了硬编码的padding值，限制了用户对编辑器间距的自定义能力。现在系统完全依赖CSS变量和自定义margin设置来控制编辑器间距。

### 自定义间距配置
```css
/* 通过CSS变量控制编辑器间距 */
.crepe-editor {
  margin: var(--editor-margin, 1rem);
  padding: var(--editor-padding, 1.5rem);
}

/* 响应式间距调整 */
@media (max-width: 768px) {
  .crepe-editor {
    margin: var(--editor-margin-mobile, 0.5rem);
    padding: var(--editor-padding-mobile, 1rem);
  }
}
```

### 用户定制优势
- **完全可控**: 用户可以通过CSS变量精确控制编辑器的所有间距
- **主题兼容**: 间距设置自动跟随主题变化
- **响应式支持**: 支持不同屏幕尺寸的间距适配
- **一致性保证**: 统一的间距控制机制确保界面一致性
