# ZenNote UI 设计文档

## 1. 设计理念



"无界面感"

&#x20;— UI 的存在是为了消失。用户打开 ZenNote，注意力应该在文字上，而不是工具上。所有辅助元素都是低存在感的陪衬。

三个设计原则：

*   克制  ：可要可不要的元素都不要，每个像素的存在都需要理由

*   安静  ：色彩、边框、阴影全部收敛，只有内容有重量

*   高效  ：高频操作有快捷键或就近入口，不打断书写流

***

## 2. 标题栏（自定义无边框窗口）

ZenNote 使用 Tauri 无边框窗口 + 自绘标题栏，与 36px 工具栏融合为一体。

```
┌─ 自定义标题栏 / 工具栏（36px）──────────────────── [─] [□] [✕] ┐
│ ☰  ≡  文件名.md                                   ⏷  ⋮         │
├─ 文件树 ───┬──────── 编辑器 ────────────┬─────── 大纲 ──────────┤
```

| 元素     | 位置          | 规格                      |
| ------ | ----------- | ----------------------- |
| 应用图标   | 左上角 8px 处   | 16×16px，无文字             |
| 窗口拖拽区域 | 图标右侧到窗口按钮左侧 | 按住空白处可拖拽移动窗口            |
| 窗口控制按钮 | 右上角         | 三个图标按钮（─ □ ✕），各 46×32px |
| 当前文件名  | 工具栏中部       | 13px，次级文字色              |



窗口控制按钮颜色

：

| 状态            | 亮色              | 暗色              |
| ------------- | --------------- | --------------- |
| 常态            | 透明              | 透明              |
| 最小化/最大化 hover | `#F0F0F0`       | `#3A3A3A`       |
| 关闭 hover      | `#E81123`（文字变白） | `#E81123`（文字变白） |



系统行为

：

* 双击标题栏空白处 → 最大化 / 还原窗口

* 标题栏按钮 tooltip 显示快捷键（如最小化、最大化、关闭）

## 3. 整体布局

```
┌─────────────┬───────────────────────────────────┬─────────────┐
│  Toolbar     │                                   │              │
│  (36px)     │                                   │              │
├─────────────┤         Editor Area                ├─────────────┤
│             │         (flex, 居中)                │              │
│  File Tree  │   ┌─────────────────────────┐      │   Outline    │
│  (240px)    │   │  ←─ 水平 padding ─→     │      │   (200px)    │
│             │   │                         │      │              │
│  Collapsible│   │    内容区域              │      │  Collapsible │
│             │   │    (max-width: 860px)   │      │              │
│             │   └─────────────────────────┘      │              │
│             │                                   │              │
├─────────────┴───────────────────────────────────┴─────────────┤
│  Status Bar (28px)                                             │
└────────────────────────────────────────────────────────────────┘
```

三栏布局，左右侧边栏均可折叠。编辑器内容区域水平居中，通过 `padding` 控制呼吸感：

| 窗口宽度     | 编辑器水平 padding | 说明        |
| -------- | ------------- | --------- |
| ≥ 1400px | 120px         | 宽屏最佳阅读体验  |
| 1200px   | 80px          | 默认窗口尺寸    |
| 900px    | 40px          | 压缩过渡      |
| < 900px  | 24px          | 最小保护，不再缩小 |

内容区 `max-width: 860px`，文字行宽控制在适合阅读的 65-75 字符范围内。

快捷键：`Ctrl+B` 文件树，`Ctrl+Shift+B` 大纲。

## 5. 字体系统

| 层级     | 字号   | 行高   | 字重  | 说明        |
| ------ | ---- | ---- | --- | --------- |
| 编辑器正文  | 16px | 1.85 | 400 | 中文书写舒适行距  |
| 编辑器 H1 | 28px | 1.4  | 700 | <br />    |
| 编辑器 H2 | 22px | 1.45 | 600 | <br />    |
| 编辑器 H3 | 18px | 1.5  | 600 | <br />    |
| 代码块    | 14px | 1.6  | 400 | monospace |
| UI 文字  | 13px | 1.3  | 400 | 工具按钮、侧边栏  |
| 状态栏    | 12px | 1.2  | 400 | <br />    |

字体回退序列：

* 正文 / UI：`"Microsoft YaHei", "Segoe UI", -apple-system, BlinkMacSystemFont, sans-serif`

* 代码：`"Cascadia Code", "Fira Code", "JetBrains Mono", Consolas, "Microsoft YaHei", monospace`

说明：中文作为首选 UI 语言，将 `Microsoft YaHei` 提到最前，确保中文字形优先匹配。正文行高从常规英文的 1.75 提升到 1.85，适应 CJK 字符较高的视觉密度。

## 6. 组件规格

### 6.1 工具栏

```
┌──────────────────────────────────────────────────────────────────┐
│ ☰  ≡                    文件名.md                          ⏷  ⋮ │
└──────────────────────────────────────────────────────────────────┘
```

* 高度 36px，背景色同编辑器，无分割线

* 左侧：折叠侧边栏按钮 `☰` + 源码模式切换 `≡`

* 中间：当前文件名（居中或左对齐）

* 右侧：大纲切换 `⏷` + 更多菜单 `⋮`（导出、设置入口）

*   不放格式按钮  ：粗体/斜体/标题完全依赖 Markdown 语法 + 快捷键，保持工具栏极简

* 所有图标 22px，hover 时 6px 圆角浅底

### 6.2 文件树

```
┌────────────────────┐
│ 📁 我的笔记    ＋  │  ← 标题行：工作区名 + 新建按钮
│                    │

│   📁 项目文档     │
│   📁 日记         │
│ ──────────────    │  ← 分割线
│ ▶ 📁 工作          │
│ ▼ 📁 学习          │
│     📄 笔记1.md    │  ← 当前文件高亮
│     📄 笔记2.md    │
│     ...            │
└────────────────────┘
```

* 标题行 32px，显示工作区文件夹名，右侧「＋」新建笔记按钮

* 当已有工作区打开时，顶部显示可切换的最近工作区列表

* 每个节点 28px，左侧缩进 12px/层

* 文件夹折叠/展开箭头 200ms 旋转动画

* 右键菜单出现于点击位置，菜单外点击关闭

* 文件名过长截断 + hover tooltip

### 6.3 编辑器内容区

```
┌─────────────────────────────────────────┐
│                                         │  ← padding (窗口 ≥ 1200px 时 80px)
│  # 第一章                               │
│                                         │
│  正文内容区域，最大宽度 860px。          │
│  行宽控制在 65-75 个字符，适合长时间     │
│  阅读和写作。                           │
│                                         │
│  当光标进入 **这段加粗文字** 时，       │  ← `**` 标记以浅色显示

│  与正文颜色明显区分。                   │
│                                         │  ← padding
└─────────────────────────────────────────┘
```

* 内容区 `max-width: 860px`，在编辑器容器内水平居中

* 水平 padding 见 2. 整体布局的响应式表格

* Markdown 语法标记（`**`、`#`、`*` 等）在光标未进入时不显示，光标进入时以浅灰色呈现

* 标记颜色值：亮色 `#C0C0C0`，暗色 `#6A6A6A`

## 7. 交互细节

*   自动保存  ：编辑停止 500ms 后自动写入文件，无任何提示。文件名旁的圆点标记消失即表示已保存。写入失败时状态栏变红提示 3 秒。

*   侧边栏折叠  ：平滑 200ms 动画（`cubic-bezier(0.4, 0, 0.2, 1)`），折叠后编辑器居中适配。

*   右键菜单  ：出现位置不溢出屏幕边缘，点击菜单外任意处关闭。

*   源码模式切换  ：`Ctrl+`` `，切换时保持光标行号。源码模式使用 CodeMirror 6 提供 Markdown 语法高亮。

*   快捷键  ：所有功能都有键盘入口，在对应按钮 tooltip 中标注。

*   文件树键盘导航  ：方向键移动焦点、Enter 打开、F2 重命名、Delete 删除、Ctrl+N 新建。

*   滚动行为  ：编辑器平滑滚动，大纲点击跳转偏移 -40px 避免被工具栏遮挡。

*   面板拖拽  ：面板间分隔条可拖拽调整宽度，范围受限，宽度保存到配置。

*   链接点击  ：`Ctrl+Click` 在浏览器打开链接，普通 Click 触发链接编辑态。

*   双击/三击  ：双击选中词（中文按标点分词），三击选中段落。

*   Ctrl+Home/End  ：跳转文档开头/结尾。

*   Ctrl+W  ：关闭当前笔记（回到空状态），不退出程序。

*   Esc  ：关闭最顶层浮层/对话框，无浮层时不做任何事。

*   切换文件  ：自动保存当前文件 → 缓存滚动位置 → 加载新文件（淡入过渡 200ms）。

*   外部文件变更  ：被外部修改时提示重新加载/保留；被外部删除时保留编辑器内容允许另存。

## 8. 空状态

*   首次启动（无工作区）  ：显示欢迎界面（见 6.10），引导选择或拖放文件夹

*   无工作区（工作区被删除后）  ：编辑器居中显示"工作区文件夹不存在"，提供"选择新文件夹"按钮，最近工作区列表在下方

*   空文件夹  ：文件树显示"尚无笔记，点击 + 创建第一篇"

*   空大纲  ：大纲面板显示灰色"无标题"

*   空文件  ：编辑器显示一个空行，光标待命

*   全局搜索无结果  ：搜索框变红 1 秒 + 显示"未找到匹配结果"

*   无工作区（首次启动）  ：编辑器居中显示「打开文件夹开始写作」，点击打开系统文件夹选择器。下方列出最近工作区（如有）。

*   空文件夹  ：文件树显示「尚无笔记，点击 ＋ 创建第一篇」

*   空大纲  ：大纲面板显示灰色「无标题」

*   空文件  ：编辑器显示一个空行，光标待命

## 10. 视觉参考

ZenNote 的设计精神可以参考：

*   Typora  ：编辑器的 WYSIWYG 体验和无 chrome 感，宽裕的内容区 padding

*   iA Writer  ：极端的克制，只保留必要元素

*   VS Code  ：侧边栏的交互模式和暗色主题参考

*   Notion  ：干净的分隔线和间距处理

ZenNote 不是其中任何一个的复刻——它比 Typora 更轻量，比 iA Writer 功能更全，比 VS Code 更专注写作。
