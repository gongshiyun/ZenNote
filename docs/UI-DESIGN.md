# ZenNote UI 设计文档（v0.9）

> 本文件是 0.9.0 视觉重做后的 UI 总览。**权威规范与逐组件细则见
> [DESIGN-CLAUDE-CODE.md](./DESIGN-CLAUDE-CODE.md)**；本文只说明布局、分层与实现落点，
> 避免两份文档对具体数值各说一套。

## 1. 设计理念

0.9.0 放弃「IDE 风」，整体转向 **Claude Code 桌面端**的设计语言：

* **克制**：可要可不要的元素都不要，每个像素都有理由
* **安静**：暖纸画布 + 1px 暖色发丝线，只有内容有重量
* **统一**：全站一套设计令牌、一套图标、一套控件；不再提供多套换来换去的配色主题

视觉特征：暖骨白 / 暖炭画布、单一陶土强调色、衬线结构标题、等宽元数据、紧凑 chrome、宽松正文。

## 2. 整体布局

```
┌─ 标题栏（40px）────────────────────────────────────────────── [─][□][✕] ┐
│ ✳ ZenNote  [▤][▥][⤴][⚙]            文档名.md        [☀][中] ───────── │
├─ 标签栏（38px）────────────────────────────────────────────────────────┤
│ [ ZenNote Redesign ×] [ Visual Language ●] [ Markdown Cheatsheet ]     │
├─ 侧栏（默认 260，可拖拽）─┬──────────────── 编辑区 ────────────────┬─ 大纲（默认 200，可拖拽）─┤
│ 工作区 ▸ 文件树           │   正文列 max-width 860px，居中          │ 大纲 / h1-h3             │
├───────────────────────────┴──────────────────────────────────────────┴──────────────────────────┤
│ 状态栏（26px）  预览 · Ln 9, Col 1 · 已保存 01:19        字数 · 字符 · 行数 · 阅读时长          │
└────────────────────────────────────────────────────────────────────────────────────────────────┘
```

* 三栏布局：文件树在左，大纲在**右**（PRD §3.4），两侧宽度可拖拽并记忆。
* 标题栏 / 标签栏 / 状态栏是 chrome，背景与编辑区同色，只用发丝线分隔。
* 没有打开文档时编辑区显示空状态：品牌标记 + 衬线标题「打开一篇笔记开始写作」+ `Ctrl+P` 提示。

## 3. 颜色 / 字体 / 尺寸

全部定义在 `src/styles/tokens.css`，逐项见 DESIGN-CLAUDE-CODE.md §2–§4。要点：

| 类别 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 `--zn-canvas` | `#FAF9F5` | `#262624` |
| 侧栏 `--zn-sidebar` | `#F0EEE6` | `#1F1E1D` |
| 主文字 `--zn-text` | `#1F1E1D` | `#F5F4ED` |
| 强调 `--zn-accent` | `#C2603F` | `#D97757` |
| 主按钮 `--zn-btn-primary-bg` | `#1F1E1D` | `#F5F4ED` |
| 选区 `--zn-selection` | `#DFE4E8` | `#3B4249` |

字体角色：无衬线 UI（`--zn-font-ui`）、衬线结构标题（`--zn-font-serif`）、等宽元数据（`--zn-font-mono`）。用户在设置中可切换编辑器字体栈（`data-font`）。

尺寸：标题栏 40 / 标签栏 38 / 状态栏 26 / 树行 28 / 圆角 6-14 / 过渡 140ms（`--zn-dur`）。

## 4. 实现分层

| 层 | 文件 | 说明 |
| --- | --- | --- |
| 令牌 | `src/styles/tokens.css` | 唯一颜色/字号/圆角/阴影/字体来源；同时保留旧变量别名，编辑器主题（`livePreviewTheme.ts`）与未迁移 widget 自动继承 |
| 基础 | `src/styles/base.css` | reset、文档根、选区、焦点环、拖拽区、可访问性工具类 |
| 原语 | `src/styles/ui.css` + `src/components/ui/*` | 按钮/图标按钮、菜单、对话框、输入、分段控件、开关、滑块、kbd、空状态、spinner；图标唯一来源 `icons.tsx` |
| 外壳 | `src/styles/shell.css` | 标题栏、标签栏、状态栏、欢迎页、应用骨架 |
| 面板 | `src/styles/panels.css` | 文件树/工作区、大纲、搜索、快速打开 |
| 对话框 | `src/styles/dialogs.css` | 设置、快捷键、查找替换、冲突条 |
| 编辑器 | `src/styles/editor.css` + `livePreviewTheme.ts` | 编辑页、源码模式、Mermaid 浮层；正文排版由 CodeMirror 主题从令牌生成 |

`src/styles/globals.css` 只做分层导入与滚动条规则（滚动条契约被 `scrollbarVisibility.test.ts` 直接读取，必须留在该文件）。

## 5. 组件与交互要点

* **标题栏**：品牌标记 + 面板开关 / 导出 / 设置；右侧外观菜单（亮/暗/系统）、语言、窗口控制；`data-tauri-drag-region` 拖拽、双击最大化。
* **标签页**：胶囊式，激活态为浮起表面 + 发丝线 + 轻阴影；未保存显示陶土圆点，hover 变 ×；右键菜单（关闭其他/左/右/全部、复制路径）。
* **文件树**：36px 工作区头（打开文件/文件夹/新建/刷新/最近工作区）、大写 section label、28px 树行、键盘导航（↑↓←→ / Enter / F2 / Delete）、内联新建/重命名、右键菜单。
* **搜索 / 快速打开**：顶部居中命令面板（640px、radius 14、shadow-modal），52px 输入行 + 结果行 + 32px kbd 提示；`role="dialog"`、焦点进入与归还、IME 安全。
* **设置**：760×620 双栏 Modal，左侧 6 个分组导航，右侧滚动内容；全部原有设置项保留（外观/字体/字号/页边距/自动保存/文件树/语言/更新/关于）。
* **查找替换**：一行式内联条（44px），复用同一个 bar 服务实时预览与源码模式；输入保持在 bar 内，不抢编辑器焦点；支持大小写/全词/正则、替换一个/全部。
* **编辑器**：正文 16px/1.75，H1/H2 衬线；行内代码 chip；围栏代码块为卡片（语言 + 复制）；表格圆角卡片；图片圆角 + 对齐工具；Mermaid 使用 base 主题 + 暖色 themeVariables；空状态。
* **状态栏**：源码/预览切换、Ln/Col、保存状态、错误、选区统计、字数/字符/行数/阅读时长。

## 6. 可访问性

* 图标按钮必须有 `title` + `aria-label`；菜单项是 `role="menuitem"` 的按钮。
* Modal/命令面板：`role="dialog" aria-modal="true"`、焦点进入/循环/归还、Esc 关闭。
* 焦点环统一陶土色 `outline: 2px solid var(--zn-accent)`；颜色对比正文 ≥ 7:1、次要文字 ≥ 4.5:1。
* 所有动画尊重 `prefers-reduced-motion`；`Ctrl+S` 等全局快捷键在输入框内不误触发。

## 7. 历史

* v0.8.x：蓝灰「IDE 风」+ 6 套可切换配色主题（zen / github / notion / paper / ocean / claude），已移除。
* v0.9.0：单一 Claude Code 桌面端设计语言（亮/暗/跟随系统），全站重做 shell、面板、对话框、编辑器表面与图标体系；补齐查找替换跨模式、IME 安全、搜索跳转、会话持久化等交互修复。
