# ZenNote 0.9.0 — 发布说明

> ⚠️ 0.9.0 的正式安装包存在「编辑器样式失效（Tauri CSP nonce 覆盖 'unsafe-inline'）」回归，请使用 **0.9.1**：[RELEASE-NOTES-0.9.1.md](./RELEASE-NOTES-0.9.1.md)。0.9.1 包含本页全部改动。
>
> 本轮目标：重新 review 需求与代码、修复问题，并把页面样式整体重做为 **Claude Code 桌面端风格**，交付可验证版本。

## 1. 视觉与体验（全站重做）

* **设计系统**：新增 `docs/DESIGN-CLAUDE-CODE.md` 与 `src/styles/tokens.css` 单一令牌源，按 `base / ui / shell / panels / dialogs / editor` 分层；`globals.css` 只保留导入与滚动条契约。
* **暖纸画布**：浅色 `#FAF9F5` / 深色 `#262624`，单一陶土强调色 `#D97757`（仅焦点、链接、当前项、开关、品牌标记），主按钮使用墨色。
* **排版**：无衬线 UI、衬线结构标题（H1/H2、欢迎页、对话框标题）、等宽元数据（路径、快捷键、代码）。
* **chrome**：40px 标题栏（品牌 + 面板/导出/设置 + 外观/语言/窗口控制）、38px 胶囊标签页（未保存陶土圆点）、26px 状态栏、右侧大纲、可拖拽面板；窗口支持 `data-tauri-drag-region` 拖动与双击最大化。
* **文件树**：工作区头、内联新建/重命名（替换阻塞式 prompt）、键盘导航、右键菜单、最近工作区、懒加载状态。
* **搜索 / 快速打开**：顶部命令面板（640px、radius 14、kbd 提示、IME 安全、`role="dialog"`、焦点归还）。
* **设置 / 快捷键 / 查找替换 / 冲突条**：全部重做；设置改为 760×620 双栏六分组 Modal；快捷键面板 2 列 25 条。
* **编辑器表面**：正文 16px/1.75、衬线 H1/H2、陶土链接与引用竖线、行内代码 chip、代码块卡片（语言 + 复制）、表格圆角卡片、图片对齐工具、Mermaid 暖色 `base` 主题、源码模式居中列、空编辑器状态。
* **图标体系**：`src/components/ui/icons.tsx` 统一线性图标，移除全部 emoji 与一次性 SVG。
* **单一配色语言**：移除 6 套可切换配色主题（themeId）；保留亮 / 暗 / 跟随系统与字体栈设置。

## 2. 功能与代码修复（节选）

### 数据安全
* **P0 修复**：存在外部冲突时退出会静默丢弃本地修改、且后台脏缓存会被写回覆盖外部版本。现在冲突文档计入未保存（关闭时提示），且任何冲突文档都不会被自动/退出冲刷。
* **P1 修复**：第二次点击关闭（首次冲刷未完成）不再让 Tauri 在保存中途销毁窗口。
* **P1 修复**：打开失败不再伪造 `# 文件名` 内容（避免首次按键自动保存覆盖真实文件），改为在状态栏报告错误。
* **P2 修复**：崩溃恢复草稿与磁盘版本不一致时显示冲突条，不再自动覆盖较新的磁盘内容。
* **P2 修复**：更新安装 / 重启前先刷新全部未保存文档；保存失败则中止安装并报错。

### 查找 / 搜索
* 查找替换提升到 AppShell，**实时预览与源码模式共用同一个查找条**；`Ctrl+F` / `Ctrl+H` 两种模式均可用。
* 修复 `zn-find-open` 事件无监听：全局搜索点击结果现在会预填查询并跳转到命中行。
* 修复查找条抢焦点 / 全局吞 Enter：焦点保持在输入框，Enter/Esc 仅在条内生效；IME 组合输入不再触发跳转。
* 修复「跳转到第 1 个命中不滚动」；`wholeWord` 在正则模式下生效。

### 编辑体验
* 新增 Markdown 自动化：列表回车续写 / 空项退格退出、Tab 列表缩进、围栏自动闭合、符号配对、`Ctrl+1…6 / Ctrl+0` 标题级别、光标在标记内时 `Ctrl+B/I/E/X/H` 取消格式。
* 大纲：改为按文档位置跳转 / 高亮，长文档（CodeMirror 虚拟渲染）不再跳错标题；`parseHeadings` 与编辑器语法对齐（Setext、缩进标题、引用内标题）。
* 排版修复：代码块 / 行内代码里的 `$...$` 不再被当成公式；HTML 导出 TOC 层级平衡、锚点一致；脚注跳过代码块。
* 修复 TOC 标签在运行时切换语言不刷新的问题（widget eq 计入 locale）。

### 平台与持久化
* 会话持久化补充：最近工作区、展开目录、面板宽度、上次编辑模式；文件树默认可见。
* `Ctrl+S` 保存、`Ctrl+N` 新建笔记补齐；快捷键面板与实际实现对齐。
* Windows 路径比较统一规范化（大小写 / 分隔符 / `..` 防护），`C:\Notes2` 不再被误判为 `C:\Notes` 内部。
* `lastWritten` 自写检测表加上 LRU 上限。
* 打包：移除 Vite 模板遗留文件；DEV-only demo harness 不再进入生产 bundle；`theme-init.js` 预置主题避免启动白闪；版本号统一 0.9.0。

## 5. 已知限制（下一轮候选）

* 文件删除仍是永久删除（未接回收站 / 撤销），文件操作错误提示只在状态栏。
* 编辑器链接点击未调用系统浏览器；拖放（图片 / `.md` / 树节点移动）未实现。
* Mermaid 渲染失败仍只有占位文案，未提供错误详情 + 重试按钮。
* 表格右键菜单可插入行/列与对齐、移动，但尚无列宽拖拽与「输入 `|` 建表」。
* 大文件（万行级）性能未优化：每次按键仍有全文扫描，属于已知风险。
* PDF 导出错误路径可能残留隐藏窗口（Rust 侧，本轮未改动该逻辑）。
* 外部冲突状态仍是单槽（同一时刻只跟踪当前文档），后台多冲突场景为后续工作。
* 安装包未做 Authenticode 签名（正式分发建议使用代码签名证书）。

完整评审记录见 `docs/REVIEW-CORE.md`、`docs/REVIEW-EDITOR.md`。
