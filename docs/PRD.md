# ZenNote 需求文档

## 1. 项目概述

| 维度   | 说明                             |
| ---- | ------------------------------ |
| 项目名称 | ZenNote                        |
| 核心理念 | 极简、轻量、小而美                      |
| 产品定位 | 本地 Markdown 笔记软件，编辑体验对标 Typora |
| 目标平台 | Windows（首期）                    |
| 笔记格式 | 纯 `.md` 文件，不锁定数据               |

ZenNote 不做云同步、不做插件市场、不做臃肿功能。它就是你的本地 Markdown 书写工具——打开就用，写完就走。

***

## 2. 技术选型

| 层面          | 技术                    | 理由                        |
| ----------- | --------------------- | ------------------------- |
| 桌面框架        | Tauri v2 (Rust)       | 包体小（\~5MB 起步），内存低，Rust 性能 |
| 前端          | React 18 + TypeScript | 生态成熟，类型安全                 |
| Markdown 引擎 | Milkdown              | 专为 WYSIWYG 设计，插件体系完整      |
| 源码编辑器       | CodeMirror 6          | 纯源码模式下的语法高亮和编辑体验          |
| 样式          | Tailwind CSS          | 原子化，适合定制极简风格              |
| 打包体积目标      | < 10MB                | <br />                    |

***

## 3. 功能需求

### 3.1 工作区管理

用户选择一个本地文件夹作为工作区根目录，所有操作围绕这个文件夹展开。

* 首次启动引导用户选择工作区文件夹

* 记住最近 5 个工作区，启动时在文件树顶部列出，点击即可切换

* 工作区路径显示在文件树标题行，点击可切换到其他文件夹

* 关闭应用时记住当前工作区路径，下次启动自动恢复

### 3.2 文件树侧边栏

* 树形结构展示工作区下所有文件夹和 `.md` 文件

* 默认隐藏非 Markdown 文件（设置中可切换为全部显示）

* 右键菜单：新建笔记（`.md`）、新建文件夹、重命名、删除

* 拖拽移动文件/文件夹到其他目录

* 当前打开的笔记高亮标识

* 有未保存更改时在文件名旁显示圆点标记

* 文件夹默认折叠，手动展开后状态持久化到本地配置

* 文件树折叠/展开动画 200ms

### 3.2a 文件操作交互细节

新建笔记

：

* 点击"＋"或 Ctrl+N → 在选中文件夹末尾出现内联输入框，预填"未命名.md"

* 光标自动选中"未命名"部分（不含 .md 扩展名）

* 输入名称后 Enter 确认，Esc 取消（取消时不创建文件）

* 新建后自动打开该文件，文件树展开到对应位置并滚动到可见

* 文件名非法字符（`\ / : * ? " < > |`）阻止输入，状态栏变红提示

重命名（内联编辑）

：

* 右键 → 重命名 或 F2 → 文件名变为可编辑 input

* 光标自动选中文件名主体（不含扩展名）

* Enter 确认，Esc 取消

* 名称冲突时拒绝并状态栏提示"该位置已存在同名文件"

删除

：

* 删除未打开的文件 → 移入回收站，状态栏提示"已移至回收站 \[撤销]"（3 秒）

* 删除当前正在编辑的文件 → 阻止，状态栏提示"文件正在编辑中，无法删除"

* 撤销删除：3 秒内点击状态栏的"撤销"→ 从回收站恢复

### 3.2b 全局搜索

* 快捷键 `Ctrl+Shift+F` 打开全局搜索面板

* 实时搜索当前工作区下所有 `.md` 文件（debounce 200ms）

* 结果列表显示文件名 + 匹配行预览 + 关键词高亮

* 点击结果 → 关闭搜索，打开文件并跳转到匹配行

* 搜索范围：文件名 + 文件内容

* 无结果时搜索框变红 1 秒 + 显示"未找到匹配结果"

### 3.2c 面板拖拽调整

* 文件树与编辑器之间、编辑器与大纲之间均可拖拽调整宽度

* 文件树范围 160px \~ 480px，大纲范围 140px \~ 360px，编辑器最小 360px

* 拖拽手柄 hover 时蓝色高亮，光标变为 col-resize

* 面板宽度保存到应用配置

### 3.2d 外部文件变更检测

* 通过文件系统监听（Rust notify crate）检测工作区内的文件变更

* 当前编辑的文件被外部修改 → 编辑器顶部显示黄色提示条 "文件已被外部修改 \[重新加载] \[保留我的版本]"

* 当前编辑的文件被外部删除 → 编辑器保留内容，状态栏提示"文件已被删除，请另存"

* 非当前文件被修改/新增 → 静默刷新文件树

### 3.3 Markdown 编辑器（核心）

> 每种语法的渲染行为、光标交互、边界情况的完整规范见 [MARKDOWN-RENDERING.md](MARKDOWN-RENDERING.md)。

#### 3.3.1 实时渲染（WYSIWYG）

对标 Typora 的核心体验：输入即渲染，不是左右分栏预览。

* 行内格式：光标进入语法区域时显示 Markdown 标记（以 40% 透明度呈现，与正文明显区分），离开后自动渲染

  * `**加粗**` → 渲染为加粗

  * `*斜体*` → 渲染为斜体

  * `~~删除线~~` → 渲染为删除线

  * `` `行内代码` `` → 渲染为代码样式

  * `[链接](url)` → 渲染为可点击链接

  * `![图片](url)` → 直接显示图片

* 块级元素：输入即生效

  * `# ~ ######` 标题 → 对应字号渲染

  * `>` 引用块 → 左边框 + 灰色背景

  * `- ` 或 `* ` 无序列表

  * `1. ` 有序列表（自动递增序号）

  * `- [ ] ` 任务列表 → 可点击勾选

  * `---` 分割线

  * ` ``` ` 代码块 → 语法高亮

#### 3.3.2 源码模式切换

* 快捷键 `Ctrl+`` `（反引号）或工具栏按钮在「实时渲染」和「纯文本源码」之间切换

* 源码模式使用 CodeMirror 6 提供 Markdown 语法高亮

* 切换时保持光标所在行号不变

* 应用记住用户最后使用的模式

#### 3.3.3 代码块

* 围栏代码块 ` ```language ` 语法

* 语法高亮覆盖主流语言（JS/TS/Python/Rust/Go/Java/CSS/HTML/JSON/YAML/SQL/Bash 等）

* 代码块右上角显示语言标签 + 复制按钮

* Tab 键在代码块内正常缩进

#### 3.3.4 表格

* WYSIWYG 表格编辑，输入 `|` 即可开始创建表格

* 工具栏按钮快速插入 N×M 表格

* 右键菜单：在上方/下方插入行、在左侧/右侧插入列、删除行/列

* 列宽可拖拽调整

* 表头自动加粗

#### 3.3.5 Mermaid 图表

* ` ```mermaid ` 代码块自动渲染为图表

* 支持的图表类型：流程图、时序图、甘特图、类图、状态图、饼图、ER 图

* 通过自定义 Milkdown nodeView 集成 mermaid.js，编辑源码时实时预览

* 焦点进入代码块时显示源码可编辑，离开后自动渲染图表

#### 3.3.6 图片

* 从剪贴板粘贴图片（`Ctrl+V`）

* 从文件管理器拖入图片

* 粘贴/拖入时自动保存到工作区根目录的 `images/` 文件夹（统一管理，避免碎文件）

* 图片在编辑器中直接显示，可点击放大查看

* 支持格式：PNG、JPEG、GIF、WebP、SVG

#### 3.3.7 数学公式（二期）

* 行内公式 `$...$` 和块级公式 `$$...$$`（KaTeX 渲染）

* 首期不包含此功能，后续迭代加入

### 3.4 侧边栏大纲

编辑器右侧的大纲面板，自动从文档标题生成。

* 提取 H1\~H3 标题生成树形目录

* 缩进表示层级关系：H1 无缩进，H2 缩进 16px，H3 缩进 32px

* 点击标题项跳转到对应文档位置

* 实时跟随编辑器滚动位置高亮对应标题（节流 100ms）

* 无标题时显示灰色「无标题」

### 3.5 字数统计

编辑器底部状态栏实时显示。

* 总字数 / 总字符数

* 选中文本时显示选中部分的字数

* 所在行号 + 列号

### 3.6 导出功能

* 导出为 PDF  ：保持 Markdown 渲染样式，可选 A4/US Letter 纸张、页边距

* 导出为 HTML  ：独立 HTML 文件，内嵌样式和图片（Base64），可直接在浏览器打开

* 导出时包含 Mermaid 图表的 SVG 渲染结果

* 快捷入口放在编辑器右上角导出菜单

### 3.7 暗色模式

* 亮色 / 暗色两种主题

* 切换按钮在状态栏右侧（低频操作不放工具栏），快捷键 `Ctrl+Shift+D`

* 支持「跟随系统」选项（默认跟随系统）

* 侧边栏、编辑器、状态栏、对话框、编辑器内部 Markdown 元素（代码块、引用、表格等）统一切换

### 3.8 编辑器辅助功能

* 撤销 / 重做  ：Ctrl+Z / Ctrl+Y

* 查找替换  ：Ctrl+F / Ctrl+H

* 自动保存  ：编辑停止 500ms 后自动保存。写入失败时状态栏短暂提示（3 秒），不弹框中断书写流

* 符号自动配对  ：输入 ( [ { " ` ` 时自动补全后半部分。详细规则见 [MARKDOWN-RENDERING.md §5](MARKDOWN-RENDERING.md)

* Markdown 结构自动补全  ：围栏代码块自动闭合、表格行自动续写、链接快捷包装

* Tab 键  ：在列表中使用 Tab 增加缩进层级，Shift+Tab 减少缩进

* 格式化快捷键  ：

* Ctrl+B：加粗（toggle）

* Ctrl+I：斜体（toggle）

* Ctrl+K：插入链接（选中文字时包裹为 [文字](url)）

* Ctrl+1 \~ Ctrl+6：设置标题级别

* Ctrl+0：取消标题

* Ctrl+Shift+X：删除线（toggle）### 3.9 应用窗口

* 使用 Tauri 无边框窗口 + 自定义标题栏（与工具栏融合，共 36px）

* 标题栏承载：窗口拖拽移动、窗口控制按钮（─ □ ✕）、当前文件名

* 双击标题栏空白处最大化/还原窗口

* 默认窗口尺寸 1200×800，最小尺寸 800×500

* 首次启动居中显示欢迎界面

* 第二次及以后启动：恢复上次窗口大小/位置 + 工作区 + 打开的文件

* 窗口标题显示当前笔记文件名

* 关闭按钮直接退出程序，退出前触发最终保存

* 窗口在已拔掉的外部屏幕上关闭过 → 启动时回退到主屏幕居中

### 3.10 错误恢复矩阵

| 场景             | 严重程度 | 恢复行为                        |
| -------------- | ---- | --------------------------- |
| 工作区文件夹不存在      | 阻断   | 提示"文件夹不存在"，从最近列表移除，引导选择新工作区 |
| 工作区无读取权限       | 阻断   | 提示"无权限访问"，引导选择其他文件夹         |
| 打开文件不存在        | 阻断   | 文件树刷新，该文件消失。如正被编辑则保留内容允许另存  |
| 保存时磁盘空间不足      | 严重   | 状态栏红字提示"磁盘空间不足"，保持 isDirty  |
| 保存时文件被锁定       | 严重   | 状态栏红字提示"文件被占用"，3 秒后自动重试     |
| 导出 HTML/PDF 失败 | 中等   | 模态提示错误原因，提供重试               |
| 粘贴图片超过 10MB    | 中等   | 弹出确认对话框                     |
| 粘贴图片格式不支持      | 低    | 状态栏提示"不支持的图片格式"             |
| Mermaid 渲染超时   | 低    | 代码块内显示"渲染超时，点击重试"           |
| 文件编码非 UTF-8    | 中等   | 尝试读取，乱码时提示"编码非 UTF-8"       |

### 3.11 切换文件行为

* 点击文件树中的文件 → 自动保存当前文件（不等 debounce，立即写盘）→ 缓存当前文件的滚动位置和光标位置 → 加载新文件

* 加载过渡：编辑器内容淡出 150ms → 新内容淡入 150ms

* 切换回之前打开过的文件时：恢复其缓存的滚动位置

* 应用重启后：恢复到上次关闭时打开的文件

### 3.14 文件树键盘导航

* 方向键 ↑/↓ 在可见节点间移动焦点

* ← 折叠已展开的文件夹 / 跳转到父节点

* → 展开折叠的文件夹 / 跳转到第一个子节点

* Enter 打开选中文件

* F2 重命名（内联编辑）

* Delete 删除

* Ctrl+N 在选中文件夹内新建笔记

* Ctrl+Shift+N 新建文件夹

* 键盘焦点样式：hover 背景 + 2px 蓝色边框

### 3.13 快捷键面板

* `F1` 弹出快捷键参考面板

* 按功能分组显示所有快捷键（文件 / 编辑 / 视图 / 格式）

* 方向键或滚轮浏览，Esc 关闭

* 默认窗口尺寸 1200×800，首次启动居中显示

* 记住上次关闭时的窗口大小和位置

* 窗口标题显示当前笔记文件名

* 关闭按钮直接退出程序

## 4. 非功能需求

| 指标                  | 目标值                                     |
| ------------------- | --------------------------------------- |
| 冷启动速度               | < 2 秒                                   |
| 空闲内存占用              | < 150 MB                                |
| 安装包大小               | < 10 MB                                 |
| 大文件（1万行 Markdown）编辑 | 无明显卡顿                                   |
| 离线可用                | 完全离线，无需网络                               |
| 编辑器主体水平内边距          | 窗口宽度 ≥ 1200px 时约 80px，随窗口缩放等比收窄，最小 24px |

***

## 5. 不做（明确排除）

* 云同步 / 多端同步

* 多标签页（首期单文件编辑）

* 插件系统 / 插件市场

* 版本历史 / Git 集成

* 移动端（iOS / Android）

* 协作编辑

* 数据库存储（纯 `.md` 文件，不用 SQLite）

* AI 功能

***

## 6. 开发阶段（建议）

### 阶段一：骨架搭建 + 基础可用

* Tauri + React 项目初始化

* 基础三栏窗口布局（文件树 + 编辑器 + 大纲）

* 工作区管理（打开、最近列表、自动恢复）

* 文件树基础版（浏览文件夹、点击打开笔记）

* Milkdown 编辑器集成，基础 WYSIWYG 渲染

* 状态栏（光标位置、字数统计）

### 阶段二：核心编辑体验

* 源码模式切换（CodeMirror 6）

* 代码高亮（Prism.js）与表格编辑

* 大纲面板（标题提取 + 滚动联动）

* 查找替换

### 阶段三：增强功能

* 文件树高级操作（右键菜单、拖拽移动、新建/重命名/删除）

* 图片粘贴/拖入

* Mermaid 图表渲染

* 暗色模式

* 自动保存 + 错误提示

### 阶段四：收官

* 导出（PDF / HTML）

* 细节打磨、测试、性能优化

* 打包 & 安装器
